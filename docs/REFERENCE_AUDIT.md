# Phase 1: Reference Video Forensic Audit

## 1. Audit Methodology
The reference video (00:00 to 00:23) was analyzed frame-by-frame on standard desktop display playback. Every visible screen, text string, animation curve, UI component, and interaction was cataloged and categorized as either **Verified Observable Fact** or **Inferred / Provisional Detail**.

## 3. Verified Observable Facts vs. Inferred Details

| Feature / Element | Verified Observable Fact | Inferred / Provisional Assumption |
| :--- | :--- | :--- |
| **Color Palette** | Background is saturated warm vermilion/orange gradient (`#EA580C` to `#9A3412`); typography is luminous cyan (`#2DD4BF`). | Subtle vignette at edges is implemented via CSS radial gradient or canvas post-processing shader. |
| **Stage Typography** | `"EOS 60D"`, `"Canon"`, `"CREATE"`, `"INSIDE"`, `"TOGETHER"`, `"e o s"` are displayed in huge uppercase sans-serif behind the camera. | Whether rendered via HTML text with CSS 3D transforms or WebGL 3D text geometry. |
| **Scroll Linking** | Scrubbing trackpad immediately drives camera rotation, zoom, and exploded trajectory. | Whether the page uses native window scroll with sticky container or a virtualized wheel event controller. |
| **Screen Articulation** | The LCD screen physically swings out on its left hinge $180^\circ$ and plays video. | Whether the video is a canvas texture (`CanvasTexture`) or an HTML `<video>` element floating with CSS 3D transforms. |
| **Exploded Disassembly** | The camera disassembles into dozens of individual components in 3D space. | Whether the 3D model was modeled as a single rigged GLB with separate bone/node hierarchies or loaded as discrete sub-meshes. |
| **Interactive Dragging** | A control pill explicitly displays `"3D - DRAG TO ROTATE"`. | Orbit limits: whether orbit dragging is clamped to $\pm 45^\circ$ or full 360° free rotation. |
